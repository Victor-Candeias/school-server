# BUG-46: Corrigir scroll vertical dos dashboards no mobile

Usar um único contentor de scroll vertical no mobile para escolas, anos
letivos, turmas e alunos, evitando linhas de grid limitadas e scrolls
aninhados que impedem o gesto de deslocação.

## Acceptance Criteria

- Os quatro dashboards permitem scroll vertical em ecrãs mobile.
- O dashboard de alunos desloca o painel completo, incluindo o submenu.
- O menu hambúrguer continua a ajustar corretamente a altura disponível.
- O comportamento desktop permanece inalterado.
