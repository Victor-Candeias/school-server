# BUG-44: Adicionar menu hambúrguer à top bar mobile

Substituir a top bar mobile sobrecarregada por um menu colapsável controlado por
um botão hambúrguer, sem alterar o layout desktop.

## Acceptance Criteria

- O botão hambúrguer é apresentado apenas no mobile.
- O botão comunica o estado aberto/fechado a tecnologias de apoio.
- Navegação, utilizador, tema, configurações e logout ficam dentro do menu.
- Selecionar uma ação fecha o menu.
- O layout desktop mantém-se inalterado.
