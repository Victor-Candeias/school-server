# FE-35: Aplicar code splitting e otimizar bundle do frontend

Reduzir o bundle inicial através de imports dinâmicos para áreas utilizadas sob
pedido, separar as bibliotecas principais em chunks próprios e disponibilizar
uma análise visual da composição do bundle.

## Acceptance Criteria

- As secções secundárias do dashboard são carregadas apenas quando abertas.
- Os submenus de alunos, incluindo os gráficos, usam imports dinâmicos.
- Os modais só descarregam o respetivo código quando são abertos.
- React e Recharts são emitidos em chunks próprios.
- `npm run analyze` produz um relatório visual em `dist/stats.html`.
- Lint, build e validação Maestru terminam sem erros.
