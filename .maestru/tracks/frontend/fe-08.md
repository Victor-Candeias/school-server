# FE-08: Implementar configurações de testes e momentos de avaliação

Adicionar às configurações uma lista persistente de templates de momentos de
avaliação. Cada template contém um tipo de momento de avaliação e a respetiva
ponderação percentual.

## Acceptance Criteria

- A secção `Templates de momentos de avaliação` aparece antes de
  `Cores da percentagem`.
- É possível adicionar, editar e remover templates.
- Cada template contém `Tipo de momento de avaliação` e `Ponderação (%)`.
- A ponderação aceita apenas valores entre 0 e 100.
- Os templates são persistidos pela API de configurações.
- Alterar os templates ativa o botão `Gravar configurações`.
- A secção é utilizável em desktop e mobile.
